Last updated: 16 November 2026

Fuel & Wrench is an app for logging refuels, service work and tires. It has no ads, no tracking, no analytics, no crash reporting and no Google services. The developer runs no server and receives no data.

What data does the app process?

• Vehicle, refuel, service and tire data you enter yourself (e.g. odometer, amount, price, station, workshop, notes, vehicle photos).
• Location (only when you tap “Current position” and have granted the permission), to recognize the station and save it with the refuel.
• Credentials for syncing (server address, user name, app password), if you set up sync.

All data is stored locally on your device. Text recognition of receipts and odometer photos runs entirely on the device; no photos are sent for it. Receipts (photos/PDFs) are, like all other data, only synced with your own sync server and included in backups you create yourself. Android backup is disabled for the app.

Where is data sent?

• Your own WebDAV/Nextcloud server: all app data and vehicle photos – when syncing (can be disabled: yes – do not set up sync)
• overpass-api.de (OpenStreetMap): coordinates, IP address – “Current position” – station search (can be disabled: yes – Settings → Privacy)
• nominatim.openstreetmap.org (OpenStreetMap): coordinates, IP address – “Current position” / “Address” – address search (can be disabled: yes – same switch)
• Android geocoder (on devices with Google services: Google): coordinates – address lookup (can be disabled: yes – off by default)
• System network location (on devices with Google services: Google): Wi-Fi/mobile data – positioning (can be disabled: yes – off by default, GPS only)
• api.github.com (GitHub): IP address – once a day check for the newest version, only for APKs installed directly (can be disabled: yes – Settings → Privacy)
• tile.openstreetmap.org: displayed map area, IP address – when opening the map (can be disabled: only by not using the map)

The privacy policies of these services apply (OpenStreetMap Foundation, FOSSGIS e. V. or Google).

Permissions

• Location (precise): only for “Current position” when refueling.
• Camera: not requested as a permission; photos are taken by the system camera app when you choose “Take photo” or “Scan”.
• Internet / network state: sync, station search, map.
• Notifications: maintenance reminders.

Retention and deletion

Data is kept until you delete it in the app or uninstall the app. You manage the data on your sync server yourself.
